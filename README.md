# Emotion Check 😃📷

Hi! My name is Seven and this is my Emotion Check project.

This is a simple AI model that can look at a picture of a face and guess if the person looks **happy** or **sad**.

I made this project using **Kaggle** and learned how to train an AI model with images.

I also learned how to run the model on an NVIDIA Jetson device.

---

## 💡 What this project does

- Looks at a face in an image or camera
- Predicts if the emotion is:
  - 😊 Happy
  - 😢 Sad
- Uses a trained machine learning model<img width="2445" height="1507" alt="final" src="https://github.com/user-attachments/assets/e664eb87-e393-49ca-bead-4388de62eebb" />

- Can run in real-time on Jetson

---

## 🧠 How I made it

I made this project by:

1. Collecting images of happy and sad faces
2. Organizing them into folders
3. Uploading the dataset to Kaggle
4. Training an image classification model
5. Testing the model on new images
6. Exporting the model to run on Jetson
